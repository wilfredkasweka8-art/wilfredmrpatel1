# Wilfred Mr. Patel — Online AI Study Tutor

Netlify-ready static frontend. No Cloudflare Workers and no GitHub deployment requirement.

## Production AI
Configure an online AI backend and voice backend in Settings. API keys should be stored server-side, never in this frontend.

## Included workflows
Dashboard, Study, Documents, Online AI Tutor, Tests, Flashcards/active recall, Progress, Mistake Book, Smart Study Planner, Feynman mode, source-grounded learning guidance, and local persistence.

## Netlify
Upload this project/ZIP as a new Netlify project. `index.html` is at the root and `netlify.toml` publishes the root directory.
